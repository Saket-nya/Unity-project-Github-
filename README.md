# Unity-project-Github-

Aura Farming



Vad är Aura Farming och sitt syfte?
Aura farming är ett 2D spel utvecklat i unity där man kan odla och sälja produkter och hantera resurser. Syftet är helt enkelt att förbättra oss inom programmering och design samt att bli mer bekväma med Unity. 


Vad använde vi för metod och hur delade vi upp arbetet?

Vi använde oss av Scrum metoden och hade 5 sprintar uppdelade i 18 veckor.

Vecka 1-3: 
Vi diskuterade fram idéer och hur vi skulle bygga upp projektet
Sprint 1 (Vecka 3-5)

Skapa Tilemap
Implementera Kameran som följer karaktären
Player movement

Sprint 2 (Vecka 6-8)
Mål: Skapa mer grunder för gameplay och farming system
Skapa farming tools
skapa system för farming

sprint 3 (Vecka 9-10)
Mål Skapa inventory och corps
Skapa ett system för inventory
Implementera grödor och ett tillväxtssystem

sprint 4 (vecka 11-15)
Mål: Ui, ekonomi och test
samla feedback av andra användare
Testa spelet och hitta buggar
Förbättra UI
Skapa en affär eller shop(optional)

sprint 5 (Vecka 16 - slut)
Mål: Förbättra allt som man kan hitta
Finslipa spelet
Kolla om alla system fungerar 



Test och Feedback

Spelet hade inte ett tydligt användargränssnitt vilket gjorde att flera testpersoner hade svårt att förstå hur inventory systemet fungerade. Det var ganska otydligt hur man valde olika frön och hur man använder dem från inventory. Det som vi gjorde var att förbättra ikonerna och andra UI element för att göra det tydligare för andra spelare.
